03 / FIRST-TIME SETUPREAD THIS
  1. Create your API connection in Printify.In Printify, open My Profile → Connections → generate a Personal Access Token. Choose the scopes shops.read, products.read, and products.write. Copy the token once and keep it private.
  2. Add the token to your website server.In Render, open your Concrete Hoops service → Environment. Add PRINTIFY_API_TOKEN, ADMIN_KEY, and, when needed, PRINTIFY_SHOP_ID. Never paste the token into a website page or browser JavaScript.
  3. Connect an API store in Printify.Open My Stores → Add a new store → API. Connect this custom Concrete Hoops website.
  4. Make and publish your products.Use the Printify Product Creator to add your shirt design, select the garment and sizes, check the mockups and retail prices, then publish to your API store.
  5. Come back here and sync.Press Sync Products. Products that are marked visible and have available variants will appear in the shop. If you have multiple Printify shops, copy the correct API shop ID shown above into PRINTIFY_SHOP_ID in Render.
KEEP YOUR TOKEN PRIVATE. A Printify token can access your account. Never send it in chat, screenshots, public GitHub code, or a browser form. The token expires after one year and must then be replaced.
